# Convert Project To Target Language

**Usage**: `/convert-project-to:ts original_project destination language`

**Example**: `/convert-project-to:ts /path/to/go-lipgloss /work/output/lipgloss typescript`

This command performs a comprehensive conversion of a project from one language to another using massive parallel processing and automated quality assurance.

## Command Arguments

- `original_project`: Path to the source project directory
- `destination`: Path where the converted project should be created
- `language`: Target language (typescript, python, rust, etc.)
